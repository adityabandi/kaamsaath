# Contributing

This project is in worker co-design, not open production development.

Before proposing a feature, explain:
1. How it changes worker take-home earnings, safety, dignity, or control.
2. Who could be harmed or excluded.
3. What field evidence would validate it.
4. What abuse or failure mode it creates.

Never commit personal data, identity documents, phone numbers, job addresses, credentials, or production conversation content.
