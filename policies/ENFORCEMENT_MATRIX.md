# Enforcement matrix - draft

| Signal/allegation | Precaution | Evidence review | Possible outcome | Appeal |
|---|---|---|---|---|
| single no-show | rematch; check welfare | contact/delivery/arrival records | no action, warning, temporary reliability limit | text/voice |
| nonpayment | pause new hirer matches when risk warrants | agreement, amount confirmations, receipts | restore, warning, temporary or permanent limit | independent human |
| harassment/threat | separate/block; temporary restriction | messages, voice, witness/evidence volunteered safely | restore, behavior warning, suspension/removal | protected text/voice |
| unsafe scope drift | let worker exit without penalty | job versions, change request, media if safe | hirer/category restriction; safety education | human |
| referral/collusion signal | hold reward only | graph/velocity/shared-device context | pay, deny reward, account restriction for proven abuse | human; shared-device explanation |
| identity mismatch | limit sensitive actions | minimally necessary verification | correction, extra assurance, restriction | assisted/local-language |
| repeated malicious false reports | protect targets; case review | evidence of knowing fabrication/abuse | warning/restriction | independent review |

Never call an unsubstantiated report false. Never use a private safety report as a public quality rating.
